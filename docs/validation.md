这些结果说明整理后的目录和构建入口可用于上述本机检查。ARM 检查没有进行完整交叉链接，本次未重新构建内核模块，也未访问真实传感器或摄像头。

已有资源基线仅覆盖特定区间：板端同一进程约 701.37 秒，平均 CPU 约 0.44%，两端 RSS 均为 1184 kB，线程数为 1，虚拟空间增加约 2.34 MiB，原因未定。这不能证明长期无泄漏或作为优化效果；当前集成帧率、端到端延时和长期稳定性仍待测量。

Windows Qt 既有数据来自 Debug 构建单点观察，未取得完整区间 CPU；原独立相机练习帧率不作为当前集成系统帧率。
