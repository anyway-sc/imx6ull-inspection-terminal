# 外置内核模块

| 目录 | 输出 | 要点 |
| --- | --- | --- |
| `icm20608` | `icm20608.ko` | 旧 `cs-gpio` 兼容、SPI 设备匹配、28 字节字符设备数据 |
| `dht11` | `vehicle_dht11.ko` | 固定 GPIO1_IO02、复用只读检查、帧校验与采样限频 |
| `sr04` | `vehicle_sr04.ko` | 固定 GPIO1_IO04/09、双边沿 IRQ、completion 和回波换算 |

构建命令及匹配内核要求见 [build.md](../docs/build.md)。DHT11/SR04 的纯逻辑头文件由本机测试覆盖，但驱动加载、微秒时序和真实输入必须在对应硬件验证。

SR501 使用已有 GPIO sysfs，不需要新增 `.ko`。AP3216C 使用板端已有适配驱动，其三个 sysfs 属性与原厂字符设备例程并非相同接口，本仓库只包含用户态读取模块。
